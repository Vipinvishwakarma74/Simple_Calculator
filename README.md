-> Simple Calculator
->Description
A simple calculator built using HTML, CSS, and JavaScript. It performs basic arithmetic operations with a clean and responsive user interface.

-> Features
- Addition
- Subtraction
- Multiplication
- Division
- Clear Button
- Responsive Design

-> Technologies Used
- HTML
- CSS
- JavaScript

-> How to Run
1. Download or clone the repository.
2. Open `c.html` in your browser.
